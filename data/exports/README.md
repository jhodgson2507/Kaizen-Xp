# Weekly exports (10 minutes, Sunday night)

1. Etsy Shop Manager > Settings > Options > Download Data: download the
   Orders CSV for last week. Save it here as orders-<YYYY-MM-DD>.csv.
2. Etsy Shop Manager > Stats: for each listing, add a line to stats.csv:

week,listing,views,favourites,orders,revenue
2026-11-02,The Visibility Kit,0,0,0,0

That is all the Shop Analyst needs.
